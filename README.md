Web Geliştirme Projeleri Portfolyosu
Proje Hakkında
Bu depo, web programlama dersi kapsamında 10 hafta boyunca HTML, CSS, JavaScript ve C# dilleriyle geliştirdiğim çeşitli web projelerini içermektedir. Projeler, temel web yapılarından interaktif uygulamalara ve basit back-end entegrasyonlarına kadar uzanan, geniş bir yelpazedeki yeteneklerimi sergilemektedir. Her bir proje, web geliştirme temellerini anlamak ve pratik deneyim kazanmak amacıyla tasarlanmıştır.

Proje Listesi ve Açıklamaları
Her bir klasör, haftalık olarak geliştirilen bağımsız bir projeyi temsil etmektedir. Aşağıda her bir projenin kısa bir açıklaması yer almaktadır:

Hafta 1-2: Temel HTML ve CSS Uygulamaları

Web sayfalarının temel yapılarını ve stil kurallarını öğrenmeye odaklanan statik web sayfaları.

Hafta 3-4: CSS Flexbox ve Grid Tasarımları

Modern ve duyarlı (responsive) web tasarımları oluşturmak için Flexbox ve Grid sistemlerinin kullanıldığı projeler.

Hafta 5-6: JavaScript Temelleri

Sayfa etkileşimini artırmak için DOM manipülasyonu ve olay dinleyicileri (event listeners) gibi temel JavaScript kavramlarının uygulandığı projeler.

Hafta 7-8: Dinamik JavaScript Projeleri

API'lerden veri çekme, form validasyonu gibi daha karmaşık JavaScript işlevlerini içeren projeler.

Hafta 9-10: C# ve Back-End Entegrasyonu

C# ile basit sunucu tarafı mantığının (örneğin, veri tabanı bağlantısı olmadan kullanıcı girişi veya form işleme) uygulandığı projeler.

Web Development Project Portfolio
About This Project
This repository serves as a portfolio of web development projects I created during a 10-week web programming course. The projects showcase my foundational skills in HTML, CSS, and JavaScript, as well as my initial steps into back-end development with C#. Each project was designed to reinforce core concepts and build practical, hands-on experience in web development.

Project List
Each folder in this repository represents an independent project developed over the course of the semester. Below is a brief overview of the projects:

Week 1-2: Foundational HTML and CSS

Static web pages created to learn the fundamental structure of HTML and basic CSS styling rules.

Week 3-4: CSS Flexbox and Grid Layouts

Projects focused on creating modern and responsive web layouts using the Flexbox and CSS Grid systems.

Week 5-6: JavaScript Fundamentals

Applications that introduce core JavaScript concepts like DOM manipulation and event listeners to add interactivity to web pages.

Week 7-8: Dynamic JavaScript Projects

More complex projects involving data fetching from APIs, form validation, and other dynamic functionalities.

Week 9-10: C# and Back-End Integration

Projects that demonstrate an understanding of server-side logic using C#, such as basic form handling without a database.
